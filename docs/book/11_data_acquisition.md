# 11. 数据获取、许可与溯源

## 问题

训练数据必须知道从哪里来、什么时候获取、能否再分发，以及未来能否重新取得同一版本。没有来源和许可信息，模型即使训练成功，也难以公开复现。

## 数据来源记录

每个数据源至少保存：

```json
{
  "source": "dataset-a",
  "url": "https://example.org/data",
  "license": "CC-BY-4.0",
  "downloaded_at": "2026-11-07T00:00:00Z",
  "raw_sha256": "...",
  "notes": "允许研究和再分发"
}
```

原始语料不提交到 Git 仓库；仓库只保存 schema、处理配置、manifest 和统计报告。

## 许可检查

需要分别检查：

- 原始数据的许可；
- tokenizer 训练数据的许可；
- 数据中引用的第三方内容；
- 是否含有个人信息或受限内容；
- 模型权重是否继承额外限制。

## 练习

为一个公开数据源建立 `source.json`，记录下载地址、版本、许可、原始文件摘要和处理命令。
