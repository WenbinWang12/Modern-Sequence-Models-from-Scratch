# 11. 数据清洗

## 问题

清洗的目标不是让数据“看起来更干净”，而是控制训练分布，同时保留可以解释的统计证据。

## 推荐流水线

```text
读取
→ JSONL schema 校验
→ Unicode 规范化
→ 空文本和异常文本过滤
→ 语言与字符比例检查
→ 长度过滤
→ 重复检测
→ 数据切分
→ token 统计
→ SHA256 manifest
```

每条被过滤的样本应有原因统计，例如 `empty`、`too_long`、`duplicate`、`invalid_unicode`。正式数据还需要单独的许可、PII、污染和安全审查流程。

## 结果记录

至少记录：

- 原始文档数和清洗后文档数；
- 原始字符数和 token 数；
- 长度分位数；
- 重复率；
- 各种过滤原因的计数；
- 训练/验证切分的样本数和 token 数。

## 练习

实现一个 deterministic 清洗命令：同一输入、同一配置和同一版本必须生成相同的 manifest 和统计报告。
