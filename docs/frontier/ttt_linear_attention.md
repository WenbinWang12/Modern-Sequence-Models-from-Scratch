# TTT 与线性注意力：相似、等价还是互补？

**快照日期：2026-11-07。状态：复现中。**

## 论文主张

TTT 原始工作把隐藏状态定义成一个在测试序列上继续更新的模型参数，并把这种层作为序列建模层。它的关键形式是：状态不再只是一个固定大小的向量，而可以是一个小模型的参数；每个 token 或 token block 到来时，通过自监督 loss 更新这个状态。[原始 TTT 论文](https://arxiv.org/abs/2407.04620)

后续工作研究了 KV binding 与线性注意力之间的关系，并提出某些 TTT 形式可以重新解释为具有更强表示能力的 learned linear attention。这个结论应该作为待复现的结构关系，而不是直接当作数学等价。[相关工作](https://arxiv.org/abs/2602.21204)

## 对照关系

| 组件 | 线性注意力 | TTT |
|---|---|---|
| 状态 | 由 key/value 累积得到的矩阵或低阶统计量 | 通过 loss 和梯度更新得到的快权重 |
| 更新 | 通常是显式递推 | SGD 或其近似更新 |
| 表达能力 | 由状态参数化和特征映射决定 | 由快模型结构和内循环步数决定 |
| 计算 | 通常每 token 固定递推成本 | 需要额外梯度和更新成本 |
| 训练目标 | 外循环训练递推规则 | 外循环训练内循环后的预测效果 |

## 本书的实验顺序

1. 先实现普通线性注意力或 delta-rule baseline；
2. 再实现相同状态尺寸的 TTT-Linear；
3. 控制 hidden size、状态参数量、训练 tokens 和实际 FLOPs；
4. 比较 loss、长上下文、首 token 延迟、稳态 tokens/s 和显存；
5. 检查两者状态更新是否在特定损失和线性模型下严格对应；
6. 再进入 TTT-E2E 的 MLP′ 和混合注意力结构。

当前仓库已有 `gated_delta.py`、分块注意力和 TTT 内循环，但还没有把“线性注意力 baseline”和“TTT-Linear 等价性证明”作为独立实验。它们应该先进入 `frontier/ttt_linear_attention/`，通过对照后再决定是否并入主线。
