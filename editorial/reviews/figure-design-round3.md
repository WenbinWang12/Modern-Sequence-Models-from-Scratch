# 第三轮配图重排与视觉验收记录

范围：清洗、去重、BPE 三组中英文 SVG，以及 BPE 对应的两份 TikZ 源。基线为 `fe3e52e`。本记录由图作者编写，不冒充独立视觉验收；外部发布流程导出后的真实预览由主代理检查。

## 设计为什么改变

上一版主要依赖相似的圆角矩形和文本说明。BPE 为了容纳完整首轮计数，出现 15–17 px 的细小文字；清洗的正文与统计副本在视觉上不够分明，去重的候选图和删除流程也较像彼此独立的卡片。

本轮统一为暖白纸面、深墨文字与 teal / indigo / amber 强调色。通过顶部章节编号、细分隔线、较大的主标题、步骤标记和留白建立阅读顺序。阴影用偏移的半透明形状构造，未使用滤镜、模糊、CSS 变量或 foreignObject。SVG 优先使用 Noto Sans CJK SC；主文字一般为 20–28 px，图题为 37 px，只有少量页眉和检索标签为 18–19 px。

颜色提供辅助线索，不能单独承担判断。候选网络同时使用实线/虚线；保留轨迹同时写 KEEP/REMOVE 或保留/删除；所有 token、rank 和计数都直接标注。图中没有把连线宽度解释为样本量，也没有用装饰性面积代替统计量。

## 三张图各自承担什么任务

| 图 | 中心问题 | 空间结构与保留的数据 |
|---|---|---|
| 清洗，1160 × 1080 | 为什么统计视图不应改写训练正文？ | 原始纸页→规范化正文为主线；虚线单向复制到统计视图；规则决定输出。四个缩进空格保持可见。完整语料的 `13=5+8` 与 `10` 次诊断另放底部，避免把单记录示例当作整批数据流。 |
| 去重，1160 × 1110 | 为什么候选、达标与删除不是一回事？ | 两条签名色带→四条候选边→按顺序保留代表。AB/BC 实线达标，AD/BD 虚线未达标；A–C 单独注明不在候选中。底部明确 `4` 对→`2` 边→`1` 篇近似删除，另给文档守恒。 |
| BPE，1160 × 1260 | 学习规则与应用规则有什么区别？ | 左上词频与基础符号，右上深墨规则档案，中间训练结束分界，下方保留位置跨度的合并带。新词只使用 rank 0/1；第二个 t 阻断 rank 2；最后单独查 ID。 |

BPE 左上不再重复正文已完整列出的八种首轮 pair 计数。图仍明确给出 `c+a` 在四种词形中的频次来源 `5+2+3+1=11`，并保留五条冻结规则及其被选中时的计数 `11,7,5,4,3`。这样让主线与字号优先，不减少正文中的完整算法证据。

## 静态语义复核清单

- 清洗字符串仍为 `"    return x + 1\n"`；代码缩进和末尾 LF 没有因示意布局被修改。统计分支没有回写箭头。底部计数明确属于完整 fixture 的手算预期。
- 去重签名列仍为 A=abcc、B=abdc、C=bbdc、D=abba。band 1 的 (a,b) 桶含 A/B/D，band 2 的 (d,c) 桶含 B/C。候选为 AB、AD、BD、BC，Jaccard 依次 3/4、2/5、1/3、3/4。
- 去重按 ID 保留 A、C、D，B 映射到 A；d02 在此前精确去重阶段映射到 d01。文档与文档对的单位没有相加。
- BPE 的词形、频次、五条规则和选择频次逐项与正文核对；catt 的跨度按 c/a→ca、ca/t→cat 收拢，第二个 t 独立保留。
- BPE 最终教学 ID 为 [7,5,0]；图注明确 ID 不等于 rank，0 是该小实验的词末标记而不是模型 EOS。
- BPE SVG 与 TikZ 从同一套图形坐标及文字生成；TikZ 简化材质，但节点位置、路径和数值相同。两份 TeX 保留 XeLaTeX 编译命令，中文使用 ctex/Fandol。

这一清单是图作者的静态检查。另已请数据审稿代理和 tokenizer 审稿代理检查图是否引入新的语义误导。

## 对抗性意见与回改

数据审稿代理指出，清洗副标题“只有训练正文进入保留文件”与同图的 `original_text` 归档矛盾。两版已改为“统计结果不覆盖训练正文”，保留文件仍明确同时保存原文、训练正文与规则版本。

Tokenizer 审稿代理指出，“No new tokens” 容易让初学者理解成编码不产生合并后的 token。两版 SVG 与 TikZ 均改为“不重新计数，不扩充词表 / No recounting. No vocabulary growth.”，限定不增长的是词表，而不是编码的结果序列。该代理逐项核对了频次、rank、阻断关系和 ID；这些语义核验仍不等于视觉渲染通过。

## 仍需真实预览检查

本代理没有本地运行 Python、JavaScript 绘图程序、XML 校验器、浏览器、TeX 或测试，也未连接远端 CPU 节点。只进行了文件编辑、文本比对与 `git diff --check`。

主代理会在既有文档发布流程中导出 PNG/PDF，并检查真实渲染后的文字、字体回退、换行和裁切。尤其要看：

1. 英文 BPE 的规则档案长行是否与右侧计数保持间距。
2. 中文与英文图题在网页正文宽度下是否清晰；18–20 px 的辅助标注是否需要放大入口。
3. 清洗下方两种计数的单位是否足够突出，是否会被误读成 c02 单条记录的结果。
4. 去重候选线上的标签是否遮挡过多连线，仍能辨认四条边。
5. TikZ 的字体宽度与 SVG 是否造成可见布局差异；未实际编译前不能标记排版通过。

正文图注需要与布局同步：清洗图的两种计数现在位于底部左右；BPE 仍保持左上词频、右上固定规则、下方编码跨度的阅读方向。移动端应提供看清原图的路径，不能仅把 1160 px 图缩成很小的静态缩略图。
