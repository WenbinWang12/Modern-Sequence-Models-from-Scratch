# 第三轮出版图视觉复核

审阅范围：清洗、去重、BPE 三组中英文 SVG，以及发布流程导出的 PNG/PDF。源代码静态审读与实际图像观察分别记账。

## 实际发布产物

GitHub Pages 发布工作流 `42888912656` 已成功完成。导出清单和六张 2 倍 PNG 均可从发布站点直接读取；对应页面也包含可横向滚动的 `figure-scroll` 容器、全尺寸图片链接和下载入口。

我逐张查看了六张已发布 PNG（清洗、去重、BPE 的中英文版本）：

- 清洗图的双分支路径、`13 = 5 + 8` 结果和 `10` 条诊断计数均完整；英文副标题和底部标签没有被裁切。
- 去重图的三步阅读顺序清楚，候选边与低于阈值的虚线可区分；英文的长标题、候选说明和底部统计在 2 倍导出尺寸内没有重叠。
- BPE 图的“计数—冻结规则—编码”三段顺序清楚，规则表、`[7, 5, 0]` ID 轨迹和停止条件均可读；英文长句没有越出卡片边界。
- 中英文版本使用同一套层级、颜色和留白规则。暖白底、深色正文、青绿主路径、靛蓝步骤和琥珀诊断在整组图中保持一致。

本轮实际图像观察未发现裁切、文字重叠、箭头断裂或关键标签落在画布外的问题。窄屏浏览器的实际触摸滚动、不同系统字体回退、PDF 阅读器显示以及 TikZ 独立编译仍未验收；这些不能由 PNG 静态观察替代。模型和数据代码测试也不属于图片导出流程，本轮没有在本地运行它们。
