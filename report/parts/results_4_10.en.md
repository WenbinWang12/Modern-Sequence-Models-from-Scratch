{% if r.sessions.ttt %}**Inference.** Table 13 reports measured session state and decoding speed. TTT-E2E's session state is the fast weights (a fixed {{ f1(r.sessions.ttt.rows[0].state_bytes.fast_weights / 1048576) }} MiB, independent of how much has been read) plus a sliding-window KV cache (also fixed); whether 2K or 32K of context has been read, the state size and the token-by-token decoding speed do not change. Full attention's KV cache grows linearly with context.

This is the method's selling point: what it pays in training buys inference cost that is constant in context length. At the scale of this report the trade is not worth it — the models are small and the contexts short, so attention is cheap anyway — and it would only pay off at longer contexts and larger serving volumes, which is beyond what this report can verify.{% endif %}
