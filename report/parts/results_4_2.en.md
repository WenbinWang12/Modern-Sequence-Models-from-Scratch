Table 1 places the final checkpoints under one held-out protocol. PG-19 test represents book text and FineWeb-Edu held-out represents web text, with both sets kept outside training. NLL and PPL measure predictive quality on each distribution, while bits per byte expresses the loss in a unit that is less dependent on tokenisation. Differences are paired on the same windows, so the intervals describe variation across matched windows rather than subtracting two unrelated means.

Read the table in the order TTT-E2E versus the sliding-window model, followed by full attention and the no-update control. The sliding-window arm keeps only a fixed recent window, full attention supplies the in-training visibility upper bound, and the no-update arm keeps TTT's parameter structure while disabling the inner loop. This ordering associates quality differences with visible context, extra parameters and actual updates. Absolute NLL values across FineWeb-Edu and PG-19 have different distributional meanings, so the paired differences and within-dataset intervals are the primary evidence.
