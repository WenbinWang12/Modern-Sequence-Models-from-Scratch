The previous sections show that TTT-E2E uses context better, but not *how*. Compressing history into fixed-size weights must lose something; two probes ask what.

{% if r.recall.ttt %}**Verbatim recall.** A 64-token span of the window is copied verbatim to a later position, and we measure how much lower the loss on the repeat is than on unmodified text. Attention can look the original up directly, so full attention gains {{ f2(r.recall.full["320"].gain) }} nats at distance 320, decaying slowly to {{ f2(r.recall.full["3712"].gain) }} nats.

Sliding-window attention falls off a cliff: {{ f2(r.recall.swa["320"].gain) }} nats at distance 320 (still inside its 512 window), then nothing — or slightly negative — once the span leaves the window ({{ f2(r.recall.swa["640"].gain) }} at distance 640). Beyond the window it has no memory of text it has read.

TTT-E2E fills that cliff, but differently from attention: {{ f2(r.recall.ttt["640"].gain) }} nats at distance 640, and then **almost no decay with distance** ({{ f2(r.recall.ttt["3712"].gain) }} nats at 3,712). That is the signature of compression into weights — information is not ordered by recency, it is accumulated into a set of weights. The cost is equally clear: the absolute size is about half of full attention's. The compression is lossy.{% endif %}

{% if r.niah.ttt %}**Single-needle retrieval.** Built after RULER's `niah` task: a sentence stating that some key's special number is a 7-digit value is hidden in haystack text, and the model is asked for it. These are 138M-parameter base models with no instruction tuning, and exact match is zero for every one of them — a row of zeros that says nothing. So we instead measure the answer's log-likelihood with the needle present against the same context with the needle replaced by an unrelated key–value pair: it asks whether the needle was used at all, even when the model cannot state the full answer.

At 32K context TTT-E2E scores {{ f2(r.niah.ttt.results.books_32768.needle_gain_per_token) }} nats/token, against {{ f2(r.niah.swa.results.books_32768.needle_gain_per_token) }} for sliding-window attention and {{ f2(r.niah.ck.results.books_32768.needle_gain_per_token) }} for the no-update control. Those two decline steadily as context grows and the needle is pushed out of the window; TTT-E2E is essentially flat from 4K to 32K.{% endif %}

Both probes point the same way: TTT-E2E keeps a memory that is **stable in distance but limited in precision**, where attention keeps one that is **precise but bounded by window or cost**. They are not the same thing, which is also why the original paper's needle-retrieval results trail full attention.
