The public benchmarks use zero-shot prompts and fixed answer normalisation. The four trained configurations in this report share the GPT-2 BPE tokenizer, and the TTT checkpoint is also evaluated with test-time updates disabled. Each public reference model is evaluated with the native tokenizer selected by its model identifier. The run metadata records the model identifier and revision. Table 6 compares the trained configurations and this no-update TTT condition, Table 8 evaluates public models with the same script, and Table 9 adds language-modelling metrics. Public models generally use far larger corpora and token budgets, so these tables provide protocol and scale context rather than a leaderboard claim for the small models.

Generation tasks are also sensitive to prompt format, context truncation and answer parsing. Valid sample counts, confidence intervals, raw JSON and script revisions should be released with the tables. The 15M byte-token pipeline diagnostics remain on the historical page and are kept separate from the 1.0 main experiment.
