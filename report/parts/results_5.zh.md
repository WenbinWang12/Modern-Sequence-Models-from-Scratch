**评测题目是否出现在训练语料里。** FineWeb-Edu 来自公开网页，而公开 benchmark 的题目本身也在网上流传，所以这一项必须实际检查而不能假定。表 13 的结果是：HellaSwag、PIQA、WinoGrande 和 OpenBookQA 没有发现逐字重合；ARC-Easy、ARC-Challenge、SciQ、LAMBADA 和 MMLU 各有不到 1% 的题目能在训练语料中找到题干原文，占比最高的是 MMLU（{{ n(r.audits.benchmark_overlap.tasks.mmlu.items_with_exact_match) }} / {{ n(r.audits.benchmark_overlap.tasks.mmlu.items_probed) }}，{{ f2(100 * r.audits.benchmark_overlap.tasks.mmlu.items_with_exact_match / r.audits.benchmark_overlap.tasks.mmlu.items_probed) }}%）。即使这些题目全部答对或全部答错，相应任务的准确率变化也不会超过这个比例，不影响第 4.7 节的任何结论。WikiText-103 test 的 {{ r.audits.benchmark_overlap.tasks.wikitext.items_probed }} 篇文章里有 {{ r.audits.benchmark_overlap.tasks.wikitext.items_with_exact_match }} 篇的片段出现在训练语料中，这在意料之内：维基百科的内容被大量网页转载。

这项检查有两个已知的盲区。第一，它只能发现逐字重合，发现不了改写、翻译或只重合答案的情况。第二，题干规范化后不足 50 个字符的题目没有参与检查（表中“检查的题目数”小于题目总数的原因），PIQA 和 OpenBookQA 因此只覆盖了一部分题目。

**训练集与 held-out 集之间的重复。** PG-19 使用官方划分。按规范化全文的摘要比对，validation 和 test 的 150 本书没有一本与训练集的 {{ n(r.audits.duplicates.pg19.train_books) }} 本书全文相同；按 PG-19 元数据里的“书名 + 作者”比对，也没有与训练集同名的书。FineWeb-Edu 的 held-out 取自训练没有用到的分片，但网页语料里存在跨分片的重复：最初取出的 {{ n(r.audits.duplicates.fineweb_edu.heldout_documents) }} 篇里有 {{ n(r.audits.duplicates.fineweb_edu.heldout_exact_duplicates_of_train) }} 篇（{{ f1(100 * r.audits.duplicates.fineweb_edu.heldout_exact_duplicates_of_train / r.audits.duplicates.fineweb_edu.heldout_documents) }}%）与训练分片中的某篇文档全文相同。这些文档已经从 held-out 集中剔除，本报告的所有 FineWeb-Edu 数字都在剔除之后的集合上计算。近似重复（例如只差页眉页脚的网页）没有检查。

**训练时实际读到了什么。** 采样器按训练种子重放的结果见第 3.2 节：两个来源的实际比例与 50/50 的目标相差不到 0.2 个百分点；整个训练只覆盖了 FineWeb-Edu 训练分片的 {{ f1(100 * r.audits.sampler_main.sources.fineweb_edu.corpus_fraction_seen) }}% 和 PG-19 训练集的 {{ f1(100 * r.audits.sampler_main.sources.pg19.corpus_fraction_seen) }}%，被读到的文本里约九成只读到一次。训练因此接近单遍训练，模型几乎没有机会靠重复来记住训练文本。
